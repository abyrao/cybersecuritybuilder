# Cybersecurity Builder

Working prototypes of the 30 example builds from **"Stop Running What Others Built: The Rise of the Cybersecurity Builder"** by Aby Rao, Triangle InfoSeCon 2026.

Each build lives in its own folder, named by build ID. Every prototype runs offline in a browser by opening its `index.html`.

**For demo purposes only. All data is fictional and does not represent any organization.**
